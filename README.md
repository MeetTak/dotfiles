## Prerequisites

- **Brew must be installed on your machine**
refer to brew official website for the installation
[brew installation](https://brew.sh/)

- **Karabiner elements for keymapping**
Install karabiner elements from the below website
[karabiner elements installation](https://karabiner-elements.pqrs.org/)

---

### Setup

Clone the repository
After cloning head over to the directory using your terminal, and run the following command

'''
stow .
'''

To install the brew packages on your machine, run the following command

'''
brew bundle install
'''
